# KetoCoachAI - Public Directory

Ce dossier contient les fichiers statiques de l'application :

- `index.html` : Page principale de l'application
- `styles.css` : Styles CSS pour l'interface
- `script.js` : JavaScript frontend avec intégration Gemini 2.5

## Déploiement Vercel

Les fichiers sont servis depuis le dossier `public/` comme configuré dans `vercel.json`.
